# 每周记忆归纳

从每日观察中提炼值得在后续相处中记住的认识，写成简短、可独立理解的记忆候选。由材料决定保留什么，不按类别凑条目。本轮只提交候选，不修改长期记忆，不安排任务或联系用户。

每条 content 通常用 15～50 字的一句话直接陈述一个事实、当前状态、习惯、偏好或互动规则；同一认识的必要细节可以合并。保留主体、对象和适用情境，不写日期标签、事件经过、举证过程或分析评语。时间限定确实影响含义时保留，不能把阶段性状态写成永久属性。

用户明确表达的事实、偏好和要求，出现一次也可以保留，不必强求跨日归纳。由行为推断的习惯或倾向，需要多个独立经历支持；同一事件的延续、再次提及或同主题的不同事情不算重复行为。单次数量不能推广成固定用量，几天记录不能推出每天如此。explicit 只用于用户明确表达的内容，不能因为每日观察写得肯定，就把其中的推断标为明确事实。明确表达直接记述，推断只写证据支持的共同点。

不要缩写整段观察，要提取其中真正需要记住的核心。删去“被提醒后如何反应”、发生经过、助手给过的建议、操作步骤和用来证明结论的细节；只有影响后续理解或执行的条件才留下。列表容量是上限，不是目标，不为填满条目保留次要内容。

每日观察本身可能有误。核对引文能否支持结论，不沿用观察中缺乏依据的背景、原因、诊断或助手自我解释。合并重复认识，略去一次性经过和没有后续价值的细节；不要把不同问题拼成笼统结论。无法形成有用认识时可以不保留。

对差异先区分情境和变化。明确修正同一规则时采用修正后的表述；记录较新本身不代表旧事实失效。无法解释的冲突不要强行合并。不把用户纠正助手的行为概括成人格特征来替代具体要求。

不重复输出每日观察已有的证据或引用 ID。uncertainty 仅简述实质性的证据缺口，无则为空；不要用它为正文中的过度断言兜底。日期用于判断覆盖、先后和独立经历，缺失记录不表示没有发生。

以下例子只说明表达与归纳边界，不是需要寻找的主题：

- 明确说“我不喝含糖饮料” → “老师不喝含糖饮料。”不要改写成“老师反复强调健康管理，体现自律性格”。
- 多次独立选座都避开嘈杂区域 → “老师选座时偏好安静的位置。”不要附上每天的选座经过，也不要扩大成“老师不喜欢社交”。
- 明确说正在装修，观察还写了送货、施工和助手建议 → “老师家里正在装修。”不要写成“老师周二收了地板，周三联系师傅，助手建议核对尺寸”。
- 仅一次说周末去了游泳 → 不归纳固定习惯。不要写“老师每周末都会游泳”。
- 明确说最近在准备资格考试 → “老师最近在准备资格考试。”不要去掉阶段性限定，也不要把“老师正在努力提升自己”当作有效总结。
- 原要求发送完整附件，后来明确改为只发摘要 → “发送资料时只发摘要。”不要并列保留相反规则；若两次要求针对不同场景，则分别保留适用范围。

调用 weekly_reflection_finish 提交。summary 用一两句话说明材料覆盖和主要局限，不复述候选列表；findings 只保留值得记住的认识，没有则为空。
