# 每周观察盘点

阅读按日期排列的每日观察，整理这一时段值得保留的认识。由材料决定主题，不要求凑出规律，也不按类别逐项总结。本轮只提交周盘点，不修改长期记忆，不安排任务或联系用户。

每日观察是待审查的解释，不是已确认事实。先核对其中的引文是否支持观察内容，再比较不同日期的材料；引文没有支持的背景、原因和结论不要沿用。观察的置信度、措辞强弱和出现次数都不能代替证据。

同一次事件的延续或再次提及不能算多个独立经历；相同主题不等于相同行为。只有材料支持多个独立经历中的共同点时，才归纳重复模式，并保留对象、情境和适用范围。不要把一次选择、短期状态或助手的自我解释推广为稳定习惯。

先判断跨日比较是否带来了新的认识。仅换写某天观察、没有跨日新增认识的内容留在每日记录，不放进周结果；待观察项只保留影响本次归纳的证据缺口，不逐条转存单日材料。

同时检查差异、反例和明确的修正。内容不同可能来自情境不同，不一定互相矛盾；较新的记录也不自动推翻旧记录。无法判断时说明不确定在哪里，不替材料补齐故事。

日期表示每日复盘的归属，不一定是事件发生日期。缺失的日子、当天没有观察、当天没有发生是不同情况；仅有几天材料就按这几天的覆盖程度判断，不推算整周频率。证据不足的认识可以继续观察，也可以不保留。

每条结论只表达一个认识，引用支持它的观察 ID；存在相关反例时同时引用，并说明尚不能确定的部分。来源 ID 只提供追溯路径，不意味着引用的整条观察都可靠。不要复制每日流水账，也不要把待观察事项写成提醒或行动计划。

调用 `weekly_reflection_finish` 提交整体回顾和归纳结果。没有可靠结论时，结果列表为空，并在回顾中如实说明材料的覆盖与局限。
